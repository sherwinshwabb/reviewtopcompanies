## Compliance notes
- None of the posts names or ranks a specific company, so no #ad/sponsored tag is required. If a future post features Citadel Gold (a paid placement on the site), add Instagram's **Paid partnership** label or "#ad" at the start of the caption, and never call it a "top pick". This matches the site's `lib/commercial.ts` rules.
- The captions make no return or performance claims, by design. Keep it that way: gold IRA marketing gets FTC/SEC scrutiny.
